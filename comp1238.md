## Week 1 - History
- People started writing about 5000 years ago in Mesopotamia.
- The first writing system was **Cuneiform**, made with a stick on clay.
- Numbers were written in **base60** (like 60 seconds in a minute).
- Other old system: **Egyptian**, **Roman**, **Chinese** and **Mesoamerican**
- Later came **printing**, **fonts** and **typewriter** we still use many of their terms today (like uppercase,lowercase).
- The first keyboards were made for typewriters and the **QWERTY** layout comes from them.

## Week 2 - Bits and Bytes
- Computers store all data using **bits (0 or 1)**
- 8 bits = **1 byte**.
- **RAM** is short-term memory; **storage** is long-term memory.
- Numbers can be written in **binary (base 2)**, **decimal(base10)**, or **hexadecimal(base16)**.
- **ASCI** is a code that connects numbers to letters (like "A" = 65).
- Text files use bytes for letters, while **binary files** store other types of data (like sound or images).
- 
## Week 3 - Text Structure
- A text file has lines, spaces, and paragraphs.
- ASCII has letters, numbers, and special symbols.
- Markup languages (Markdown, HTML, XML, JSON) give structure to text.
- Json and XML store data in a simple, readable way.
- Markdown is easy to write and very popular for notes and websites.
- 
## Week 4 - Working with Text
- Good keyboard skills make typing faster and easier.
- There are many keyboard layouts like QWERTY and DVORAK.
- Text editors like Notepad, VS Code, and Vim are used to edit text.
- We can search text using **wildcards** or **regular expressions (RegEx)**
- Example RegEx : [0-9]+, <[1-6]>, \d{3}-\d{2}-\d{4}.they find patterns in text.
- 
## Week 5 - Command Line Interface (CLI)
- The command line lets us talk to the computer with text.
- Basic commands: ls,pwd, cd, cat, mkdir.
- Use **pipes(I)** and **redirects(>,>>)** to send output to other commands or files.
- **SSH** connects to other computers safely.
- **scp** and **sftp** move files; **tmux** keeps work running in the terminal.
